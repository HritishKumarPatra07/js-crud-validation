# 📋 JavaScript CRUD Application

A complete **CRUD (Create, Read, Update, Delete)** application built using **HTML, CSS, and JavaScript** with client-side form validation.

## ✨ Features

- ➕ Add New Record
- 📖 View Records
- ✏️ Update Existing Record
- 🗑️ Delete Record
- ✅ Form Validation
- 🔍 Search Functionality (if available)
- 🆔 Auto Generated ID
- 📱 Responsive Design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 📂 Project Structure

```
CRUD_PROJECT/
│
├── index.html
├── style.css
└── script.js
```

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start adding, editing and deleting records.
